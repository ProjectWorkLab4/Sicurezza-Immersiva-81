# Design Interactions

| Interaction | Buttons |
| - | - |
| Targeting | Indirectly using a ray cast. |
| Selection | Activate that interactable with the controller using the Trigger button |
| Select, accept | Trigger Buttons, X/A |
| Grab | Grip Buttons |
| Menu navigation, Locomotion | Thumbstick |  
| Back out, cancel | Y/B |  
| Open or Close the Universal menu | Meta Button, it is an OS-level feature and is not customizable. |
| Bring up or dismiss an in-app Menu | Menu Button |
